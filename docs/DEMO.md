# Demo script

Three ways to show the project, from no setup to the full pipeline. Each takes a few minutes.

## A. No keys at all: demo mode

```bash
uv sync
uv run python scripts/serve_demo.py
```

1. Open <http://localhost:8000/docs>: the endpoints, request and response shapes, generated by FastAPI.
2. Open <http://localhost:8000/ui>: the yellow "demo mode" badge.
3. Open "Documents in this collection": 20 synthetic documents, 4 of them PDFs with 3 pages each.
4. Click a sample question, then Ask:
   - green `answered`, the quote highlighted inside the source chunk, document title and page;
   - an unanswerable question (e.g. a student discount) returns `abstained`: "Not in the documents.";
   - the replay passed through the same evidence check as a live answer.
5. Ask a question that is not recorded: the service refuses with "this question is not recorded"
   instead of inventing an answer.

Stop with `Ctrl+C`.

## B. Free live retrieval (no paid API)

```bash
docker compose up -d db
uv sync --extra local
uv run --extra local python scripts/ingest_corpus.py
uv run --extra local uvicorn app.main:app
```

Open <http://localhost:8000/ui>, paste `API_KEY` from `.env`.

1. Click "What are the payment terms with Trailworks Equipment Co.?", then "Show retrieved chunks
   only": the top chunks with document, page and score, no Claude call.
2. Switch the retrieval mode between `vector` and `hybrid` and compare.
3. Upload a text PDF under "Add a document": pages and chunks are reported. Upload a non-PDF or a
   scanned PDF: a clear 422 message.
4. Press Ask: 503 "ANTHROPIC_API_KEY is not set". The service says what is missing instead of
   failing silently.
5. Show the retrieval chart: `results/retrieval_bge-large-en-v1.5.png`.

## C. Full pipeline (needs `ANTHROPIC_API_KEY` in `.env`; small cost per question)

Same as B, with the key set. Good questions to show:

| Question | What it shows |
|---|---|
| How many days do customers have to return unused items? | decoy: the superseded 2025 policy has a different number; the answer must cite the current one |
| What are the payment terms with Trailworks Equipment Co.? | decoy pair: Alpinewood says net 30, Trailworks net 45 (PDF, page number) |
| My tent fabric was damaged by the sun after two seasons. Will the warranty pay? | paraphrase; the quote crosses a line break in the PDF and still matches |
| Does Harbor Goods offer a student discount? | not in the documents: `abstained` |

Point at: the status badge, the highlighted quote, the page (copied from the stored chunk, never
from the model), and `retried` when the first answer failed the check.

## The 30-second explanation

"The model's answer is treated as untrusted input. It must quote the exact text it used. Code
checks that every quote really exists in what was retrieved for this question, and that every
number in the answer is in a quote. If not, it gets one retry with the exact errors; if it still
fails, nothing is shipped and the case goes to a person. Questions the documents cannot answer are
refused. All of it is measured on 60 test questions, and every miss is listed."
